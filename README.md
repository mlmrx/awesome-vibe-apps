# Awesome Vibe Apps

> A source-linked directory of apps built with AI coding tools.

Discover apps and projects from GitHub, the open web, and public posts on X. Each entry links to the project and to public evidence from its creator about how it was built.

This is a growing community directory, not a claim that every vibe-coded app has been found. The catalog is curated from public sources and is open to corrections and additions.

## What belongs here

- An app, website, game, or installable project that people can try, install, or inspect in a public source repository.
- A public, first-party signal from its creator or project that AI coding tools played a meaningful role in building it.
- A short, factual description, a working project link, and a link to the build evidence.

We use “vibe coded” broadly for projects whose builders describe a meaningful AI role in the build. We do not infer it from a site's appearance, framework, or generated-code detector. Entries record public claims; they are not independent audits of authorship, quality, security, or availability.

## Apps

### Community

- **[Dev Confessions](https://worksnever.dev/)** — Anonymous space for developers to share confessions, wins, failures, and discoveries. Built with Lovable, according to the creator's [build story](https://dev.to/willdew-dev/building-my-first-vibe-coded-app-without-touching-a-line-of-code-4pld). **Checked:** 2026-10-22.

### Food and dining

- **[MenuGen](https://menugen.app/)** — Turns a photo of a restaurant menu into images that help explain the dishes. The creator describes the app and its Cursor + Claude build in a [first-person write-up](https://karpathy.bearblog.dev/vibe-coding-menugen/), with a companion [post on X](https://x.com/karpathy/status/1917961248031080455). **Checked:** 2026-10-22.

### Mobile apps

- **[Expense Manager for Small Businesses](https://github.com/maanuanubhav999/vibe-coded-expense-manager)** — Android expense tracker with entries, date and category views, and weekly summaries. Its [repository README](https://github.com/maanuanubhav999/vibe-coded-expense-manager#readme) says it was fully vibe coded with ChatGPT and Claude. **Checked:** 2026-10-22.

### Productivity

- **[FastTodo](https://vibe-coded-todo-app.vercel.app/)** — Offline-first task manager with multiple lists, task metadata, and sync. The creator identifies it as vibe coded in the [project repository](https://github.com/imran-baitham/vibe-coded-todo-app). **Checked:** 2026-10-22.

## Add an app

Open a pull request with an entry or [suggest one in an issue](https://github.com/mlmrx/awesome-vibe-apps/issues/new). Include the app or repository link, a concise description, a category, and the creator's public build statement. See [CONTRIBUTING.md](CONTRIBUTING.md) for the entry format and review rules.

## Discovery

We look for leads in public GitHub repositories, app galleries, product sites, launch write-ups, and public posts on X. A discovery post is not enough by itself: each listing should link to the project and to the public build evidence.
